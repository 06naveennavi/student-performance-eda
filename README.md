# Student Performance EDA

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a real-world student performance dataset.

## 📊 Objectives
- Understand student score distribution
- Analyze impact of test preparation
- Study correlation between subjects
- Explore effect of parental education

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📈 Key Insights
- Students who completed test preparation scored higher
- Reading and writing scores are strongly correlated
- Female students perform better in reading and writing
- Parental education impacts performance

## 📂 Dataset
Dataset sourced from Kaggle

## 🚀 Conclusion
EDA helps uncover patterns and relationships in data before applying machine learning models.
